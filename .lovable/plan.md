# CreditRiskAI 前端 MVP 实施方案

## 目标
构建一个可直接演示的企业级信贷风险分析助手，完整覆盖客户资料、AI 客户画像、风险分析、依据溯源、分析报告、工作台和设置，并按需求串联主要操作流程。

## 页面与体验
- 建立固定顶部栏与左侧导航，桌面端保持高信息密度，移动端转换为紧凑菜单。
- 默认进入“客户资料”，支持拖拽与点击选取文件，并展示解析完成的资料清单。
- “开始AI分析”进入客户画像；客户画像展示 4 项财务指标与初步洞察。
- “查看风险分析”进入风险页，展示综合等级、风险统计、置信度、合规提示与分项风险。
- 首项“查看依据”进入详情，展示关键数据对比、推理步骤和原文溯源；“查看原文”打开文档预览弹窗。
- “加入分析报告”进入完整贷前风险分析报告；支持模拟重新生成、保存草稿与导出 PDF 下载。
- 补齐工作台、设置，并为侧栏“AI分析报告”等每一项提供可操作内容。

## 视觉方向
- 白色与浅灰为主，经典金融蓝为主要操作色，深灰黑用于信息层级。
- 风险状态仅使用克制的红、橙、绿标记；卡片小圆角、细边框、轻阴影。
- 采用专业中文无衬线排版，不使用炫光、霓虹或夸张渐变。

## 技术说明
- 使用现有 React/TanStack Start 与 Tailwind CSS，不连接真实 AI 或数据库。
- 单页状态管理实现导航、上传、弹窗、保存状态和浏览器端模拟下载。
- 统一语义化颜色变量，并补齐页面标题、描述与社交分享元信息。
- 完成后检查桌面与移动端显示，以及主要点击链路和下载行为。
